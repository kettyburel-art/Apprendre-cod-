🌿 Ton Plan d'Apprentissage

De zéro à développeuse web en 12 semaines

Conçu spécialement pour toi, avec Flōra comme projet fil rouge

🎯 Progression structurée

Semaines 1-2

Fondamentaux : Construire tes bases

📚 Concepts à comprendre

  • Les 3 piliers du web (HTML, CSS, JavaScript)
  • Comment fonctionne un navigateur
  • Structure d'une page HTML
  • Balises essentielles

💻 À faire

  • Créer ta première page HTML (Hello World)
  • Ajouter du texte, des titres, des paragraphes
  • Créer une liste de courses en HTML
  • Lire le guide complet (Sections 1-3)

📁 Petit projet : Ma première page

Crée une page "À propos de Flōra" avec : - 1 titre principal - 3 paragraphes de description - 1 liste de recettes

HTML Structure
Ne te presse pas. Comprendre correctement les bases te fera gagner des heures plus tard !

Semaines 3-4

CSS : Rendre ta page belle

📚 Concepts à comprendre

  • Sélecteurs CSS (par balise, classe, ID)
  • Propriétés essentielles (color, font, padding, margin)
  • Box model (padding, margin, border)
  • Flexbox et Grid (introduction)

💻 À faire

  • Styliser ta page "À propos de Flōra"
  • Créer des classes CSS réutilisables
  • Utiliser les couleurs Flōra (vert sage #6b9e87, coral #e8a995)
  • Rendre la page responsive (mobile-friendly)

🎨 Projet : Landing page Flōra

Crée une page d'accueil Flōra avec : - Header avec logo et titre - Section "À propos" stylisée - Liste de recettes avec cartes stylisées - Footer

CSS Layout Responsive
Utilise Flexbox pour l'alignement. C'est plus facile que de maîtriser Grid au début.

Semaines 5-6

JavaScript : Ajouter l'interactivité

📚 Concepts à comprendre

  • Variables et types (let, const, number, string, boolean)
  • Fonctions et comment les appeler
  • Conditions (if/else)
  • Boucles (forEach est suffisant pour débuter)

💻 À faire

  • Créer des variables pour les recettes
  • Écrire une fonction qui calcule les calories totales
  • Afficher/cacher des éléments avec JavaScript
  • Utiliser console.log() pour déboguer

⚡ Projet : Calculatrice de calories

Une app simple qui : - Affiche 3 recettes avec leurs calories - Permet de cliquer pour voir les détails - Calcule le total de calories - Affiche "léger" si < 300 cal, "riche" sinon

JavaScript Variables Conditions
console.log() est ton meilleur ami. Ajoute-le partout pour comprendre ce qui se passe.

Semaines 7-8

DOM : Maîtriser la page

📚 Concepts à comprendre

  • Le DOM (Document Object Model)
  • Sélectionner des éléments (getElementById, querySelector)
  • Modifier le contenu (textContent, innerHTML)
  • Ajouter des événements (addEventListener)
  • Ajouter/retirer des classes CSS

💻 À faire

  • Changer le texte d'une recette en cliquant dessus
  • Ajouter une recette à "Mon repas" dynamiquement
  • Supprimer une recette de "Mon repas"
  • Mettre à jour l'affichage en temps réel

🖱️ Projet : Mini Flōra interactive

Le projet du guide ! Une app fonctionnelle avec : - Liste de recettes cliquables - Ajouter au repas - Supprimer du repas - Total de calories mise à jour

DOM Événements Interactivité
C'est là que ta page devient vraiment vivante. Prends du temps pour bien comprendre le DOM.

Semaines 9-10

localStorage & API : Aller plus loin

📚 Concepts à comprendre

  • localStorage pour sauvegarder les données
  • JSON (format de données)
  • Fetch API pour récupérer des données
  • Promises et .then()

💻 À faire

  • Sauvegarder les favoris dans localStorage
  • Récupérer les favoris au rechargement
  • Charger les recettes depuis un fichier JSON
  • Afficher un message de chargement pendant que les données arrivent

💾 Projet : Flōra avec favoris

Améliore ton Mini Flōra : - Ajouter/retirer des favoris (cœur) - Sauvegarder dans localStorage - Charger les recettes depuis data.json - Les favoris persistent après rechargement

localStorage JSON Fetch
⚠️ localStorage ne fonctionne pas dans les artifacts Claude. Tu peux l'utiliser dans une vraie app sur GitHub Pages.

Semaine 11

Débogage & Bonnes pratiques

📚 Concepts à comprendre

  • Utiliser la console du navigateur (F12)
  • Identifier les types d'erreurs
  • Écrire du code propre (noms explicites, commentaires)
  • DRY : Don't Repeat Yourself

💻 À faire

  • Nettoyer ton code Mini Flōra
  • Ajouter des commentaires pertinents
  • Refactoriser les fonctions répétitives
  • Tester avec la console

✅ Projet : Code audit

Revise ton code Mini Flōra et : - Améliore les noms de variables - Réduis la duplication - Ajoute des commentaires clairs - Vérifie que tout fonctionne

Débogage Qualité de code Refactoring
Le code qui fonctionne est bien. Le code propre est mieux. Très mieux.

Semaine 12

Ton propre projet ! 🎉

📚 C'est l'heure de briller !

Tu as maintenant TOUS les outils pour créer une véritable app web. À toi de choisir !

💡 Idées de projets personnels

  • Liste de courses : Ajouter/retirer items, sauvegarder
  • Budget perso : Suivre les dépenses, voir les stats
  • Tracker de douleur : Pour suivre tes SJSR
  • Planner de repas : Planifier la semaine avec Flōra
  • Journal : Écrire et sauvegarder tes notes

🚀 Projet final : Ton app personnelle

Crée une app qui t'est utile AU QUOTIDIEN. Les meilleures apps naissent d'un besoin réel.

Minimum requis :

  • HTML + CSS fonctionnels
  • Au moins 3 fonctions JavaScript
  • Sauvegarder et récupérer les données
  • Interface propre et responsive
HTML CSS JavaScript DOM localStorage Créativité
C'est TON projet. Fais ce qui te plaît. Partage-le ensuite sur GitHub !
