HTML : Structure

Balises de base

Texte

HTML<h1>Titre</h1> <p>Paragraphe</p> <strong>Gras</strong> <em>Italique</em>

Listes

HTML<ul> <li>Élément 1</li> <li>Élément 2</li> </ul>

Liens et boutons

HTML<a href="https://google.com">Lien</a> <button onclick="action()">Clic moi</button>

Formulaires

HTML<input type="text" id="nom" placeholder="Ton nom"> <input type="number" id="calories"> <textarea id="notes"></textarea> <select id="categorie"> <option>Petit-déj</option> <option>Déjeuner</option> </select>
Utilise les type="" pour valider automatiquement : email, date, number, etc.

Structure de page

HTML<!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <title>Ma page</title> </head> <body> <!-- Contenu --> </body> </html>
CSS : Style

Sélecteurs

CSS/* Par balise */ p { color: blue; } /* Par classe */ .recette { background: white; } /* Par id */ #titre { font-size: 2em; } /* Enfant direct */ .recette > p { margin: 0; } /* Tous les enfants */ .recette p { color: gray; }

Couleurs et fonts

CSScolor: #6b9e87; background: rgba(0, 0, 0, 0.1); font-size: 1.5em; font-family: 'Arial', sans-serif; font-weight: bold; text-align: center; line-height: 1.5;

Spacing et Layout

CSSpadding: 20px; /* Intérieur */ margin: 10px; /* Extérieur */ border-radius: 8px; /* Coins */ box-shadow: 0 2px 8px rgba(0,0,0,0.1); width: 100%; max-width: 800px;

Flexbox

CSS.container { display: flex; justify-content: center; /* Horizontal */ align-items: center; /* Vertical */ gap: 20px; /* Espace entre items */ flex-direction: column; /* ou row (défaut) */ }
Flexbox = le super pouvoir du CSS. Parfait pour les layouts

Grid

CSS.grid { display: grid; grid-template-columns: 1fr 1fr 1fr; /* 3 colonnes égales */ grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); gap: 20px; }
Grid = pour les layouts complexes avec lignes et colonnes
JavaScript : Logique

Variables et types

JavaScriptlet nom = "Ketty"; // Texte let age = 49; // Nombre let actif = true; // Booléen let tableau = [1, 2, 3]; // Array let objet = { nom: "Flōra", calories: 250 };
var est ancien. Utilise let ou const à la place.

Fonctions

JavaScriptfunction addCalories(cal1, cal2) { return cal1 + cal2; } // Fonction fléchée (moderne) const double = (x) => x * 2; // Appeler console.log(addCalories(100, 200)); console.log(double(5));

Conditions

JavaScriptif (calories > 300) { console.log("Riche"); } else if (calories > 150) { console.log("Moyen"); } else { console.log("Léger"); } // Ternaire (court) let type = calories > 300 ? "Riche" : "Léger";

Boucles

JavaScript// for classique for (let i = 0; i < 5; i++) { console.log(i); } // forEach (recommandé) recettes.forEach(recette => { console.log(recette.nom); }); // while let i = 0; while (i < 5) { console.log(i); i++; }

Objets et Arrays

JavaScript// Array let arr = [1, 2, 3]; arr.push(4); // Ajouter arr.pop(); // Retirer dernier arr.length; // Longueur // Objet let recette = { nom: "Salade", cal: 250 }; recette.nom; // "Salade" recette["cal"]; // 250 // Ajouter propriété recette.tags = ["vegan", "rapide"];

Filter, Map, Find

JavaScript// Filter : garder certains éléments let legeres = recettes.filter(r => r.calories < 300); // Map : transformer chaque élément let noms = recettes.map(r => r.nom); // Find : trouver un élément let salade = recettes.find(r => r.nom === "Salade"); // Some : vérifier si au moins 1 correspond let hasLight = recettes.some(r => r.calories < 200);
DOM : Contrôler la page

Sélectionner des éléments

JavaScript// Par id (un seul) let el = document.getElementById("monId"); // Par classe (le premier) let el = document.querySelector(".recette"); // Par classe (tous) let els = document.querySelectorAll(".recette"); // Accéder aux enfants el.children; // Éléments HTML directs el.firstChild; // Premier enfant

Modifier le contenu

JavaScript// Changer le texte el.textContent = "Nouveau texte"; // Ajouter du HTML el.innerHTML = "<p>Contenu HTML</p>"; // Ajouter un élément let newDiv = document.createElement("div"); el.appendChild(newDiv); // Supprimer un élément el.remove();

Modifier les classes CSS

JavaScript// Ajouter classe el.classList.add("active"); // Retirer classe el.classList.remove("active"); // Toggle (ajouter si absent, retirer si présent) el.classList.toggle("active"); // Vérifier el.classList.contains("active");

Événements

JavaScript// Ajouter un événement button.addEventListener("click", function() { console.log("Cliqué !"); }); // Avec une fonction fléchée button.addEventListener("click", () => { console.log("Cliqué !"); }); // Événements courants // click, change, input, submit, mouseover, mouseout
Utilise addEventListener au lieu de onclick
localStorage : Données persistantes

Operations basiques

JavaScript// Sauvegarder localStorage.setItem("clé", "valeur"); // Récupérer let valeur = localStorage.getItem("clé"); // Supprimer localStorage.removeItem("clé"); // Vider tout localStorage.clear(); // Longueur localStorage.length;
Ne fonctionne PAS dans les artifacts Claude.ai. Utilise sur GitHub Pages.

Exemples Flōra

JavaScript// Sauvegarder les favoris localStorage.setItem("favoris_1", "true"); localStorage.setItem("favoris_5", "true"); // Vérifier si favori if (localStorage.getItem("favoris_1")) { console.log("C'est un favori !"); } // Récupérer tous les favoris let favoris = []; for (let i = 0; i < localStorage.length; i++) { let key = localStorage.key(i); if (key.startsWith("favoris_")) { favoris.push(key); } }
API : Récupérer des données

Fetch basique

JavaScriptfetch('https://api.example.com/data') .then(response => response.json()) .then(data => { console.log(data); // Faire quelque chose }) .catch(error => { console.error("Erreur:", error); });

Fetch avec POST

JavaScriptfetch('https://api.example.com/save', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ nom: "Salade", calories: 250 }) }) .then(response => response.json()) .then(data => console.log(data));

Chargement depuis JSON local

JavaScriptfetch('/data/recettes.json') .then(response => response.json()) .then(recettes => { recettes.forEach(r => { console.log(r.nom); }); });
Parfait pour charger les données de ton app au démarrage
Débogage : Trouver les erreurs

Console

JavaScript// Afficher une valeur console.log("Texte: " + variable); // Afficher un objet complet console.log(objet); // Afficher un tableau console.table(recettes); // Avertissement console.warn("Attention !"); // Erreur console.error("Erreur grave !");
Ouvre la console avec F12 → Onglet "Console"

Debugger dans le code

JavaScript// Pause l'exécution ici debugger; function recalculer() { debugger; // Pause quand elle est appelée return calories * 1.5; }
Utilise F12 pour pas-à-pas dans le code. Puissant !

Erreurs courantes

Erreurs// undefined : variable n'existe pas console.log(variable_inexistante); // null : valeur intentionnellement vide let x = null; // NaN : Not a Number let y = "texte" * 2; // NaN // TypeError : type incorrect let arr = [1, 2, 3]; arr.forEach(x => {}); // OK "texte".forEach(x => {}); // ERREUR
