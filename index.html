🎯 Les Fondamentaux : Comprendre l'Architecture Web

Avant de coder, comprends comment fonctionne une page web. Flōra en est un excellent exemple !

Les 3 piliers du web

1. HTML (HyperText Markup Language)
La structure et le contenu. C'est comme les murs d'une maison.
2. CSS (Cascading Style Sheets)
L'apparence et le style. C'est comme la peinture et la décoration.
3. JavaScript
L'interactivité et la logique. C'est comme l'électricité qui fait fonctionner la maison.
Flōra en 3 piliers
HTML : Les recettes, les boutons, les champs à remplir
CSS : Les couleurs apaisantes (vert sage, coral), les polices, les animations
JavaScript : Chercher une recette, compter les calories, sauvegarder un repas

🏗️ HTML : Construire la structure

Qu'est-ce que c'est vraiment ?

HTML c'est un langage de balises qui structurent le contenu. Chaque balise dit au navigateur : « Ici, c'est un titre », « Ici, c'est un bouton », etc.

Les balises essentielles

<h1> à <h6>
Titres (h1 = plus gros, h6 = plus petit)
<p>
Paragraphe de texte
<button>
Un bouton cliquable
<input>
Champ pour saisir du texte
<div>
Conteneur (zone de regroupement)
<ul>, <li>
Liste à puces

Un exemple : Afficher une recette Flōra

Voici comment Flōra affiche une recette en HTML :

HTML <div class="recette"> <h2>Salade Pois Chiches Basilic</h2> <p>250 cal | Anti-inflammatoire</p> <button onclick="ajouterAuRepas()">Ajouter au repas</button> </div>
Explication mot par mot
<div class="recette"> = On crée une zone pour la recette
<h2> = Le nom de la recette (titre)
<p> = Les infos nutritionnelles
<button> = Le bouton pour l'ajouter au repas
onclick="ajouterAuRepas()" = Quand on clique, ça exécute la fonction JavaScript

Structure minimale d'une page HTML

HTML Structure <!DOCTYPE html> <html lang="fr"> <head> <meta charset="UTF-8"> <title>Flōra - Recettes Anti-inflammatoires</title> </head> <body> <h1>Bienvenue dans Flōra</h1> <p>Trouvez des recettes saines.</p> </body> </html>

🎨 CSS : Faire briller la page

Qu'est-ce que c'est vraiment ?

CSS te permet de colorier, changer la taille, positionner les éléments HTML. C'est l'art du web !

Comment ça marche ?

Tu sélectionnes un élément HTML et tu lui appliques des propriétés.

CSS Syntaxe sélecteur { propriété: valeur; propriété: valeur; }

Les propriétés essentielles

color
Couleur du texte
background
Couleur de fond
font-size
Taille du texte (px, em, %)
padding
Espace intérieur
margin
Espace extérieur
border-radius
Coins arrondis

Exemple Flōra : Styliser une recette

CSS .recette { background: white; padding: 20px; border-radius: 10px; box-shadow: 0 2px 8px rgba(0,0,0,0.1); color: #6b9e87; } .recette h2 { font-size: 1.5em; color: #6b9e87; }
Ce que ça fait
La recette a un fond blanc, de l'espace intérieur (padding), des coins arrondis, et une légère ombre pour la profondeur. Le texte est en vert sage (couleur Flōra).

3 façons de sélectionner un élément

CSS Sélecteurs /* Par balise */ p { color: blue; } /* Par classe */ .recette { background: white; } /* Par id (unique) */ #boutonsauvegarder { background: green; }

⚡ JavaScript : Ajouter l'interactivité

Qu'est-ce que c'est vraiment ?

JavaScript c'est un langage de programmation qui permet à ta page de FAIRE des choses : réagir aux clics, calculer, sauvegarder, etc.

Les 5 concepts clés

1. Variables
Des boîtes pour ranger les données (texte, nombre, objet).
Variables let nom = "Flōra"; let calories = 250; let recettes = ["Salade", "Soupe", "Gratin"];
2. Fonctions
Un bloc de code réutilisable qui fait une action précise.
Fonction function ajouterAuRepas() { console.log("Recette ajoutée !"); } // Appeler la fonction ajouterAuRepas();
Dans Flōra
Quand tu cliques sur "Ajouter au repas", JavaScript appelle une fonction qui sauvegarde la recette dans ton repas du jour.
3. Conditions (if/else)
Faire une action SI quelque chose est vrai.
Conditions if (calories > 300) { console.log("Recette riche en calories"); } else { console.log("Recette légère"); }
4. Boucles (for, forEach)
Répéter une action plusieurs fois.
Boucle classique for (let i = 0; i < recettes.length; i++) { console.log("Recette: " + recettes[i]); } // Affiche chaque recette une par une
Boucle moderne (forEach) recettes.forEach(function(recette) { console.log("Recette: " + recette); }); // Plus lisible et moderne en JavaScript
5. Objets
Regrouper plusieurs informations liées (comme une recette avec ses infos).
Objet let recette = { nom: "Salade Pois Chiches", calories: 250, duree: 15, tags: ["vegan", "rapide", "santé"] }; console.log(recette.nom); console.log(recette.calories);
Dans Flōra, chaque recette est un objet
Avec le nom, les calories, les ingrédients, les étapes, les tags. JavaScript parcourt les recettes avec une boucle et les affiche à l'écran.

🖱️ DOM : Contrôler la page

Qu'est-ce que c'est vraiment ?

Le DOM (Document Object Model), c'est la représentation en arbre de ta page HTML. JavaScript peut la modifier en temps réel !

Les opérations essentielles

Sélectionner un élément
Accéder à un élément HTML pour le modifier.
Sélectionner // Par id let bouton = document.getElementById("monBouton"); // Par classe (le premier) let premiere = document.querySelector(".recette"); // Par classe (tous) let recettes = document.querySelectorAll(".recette");
Modifier le contenu
Changer le texte ou le HTML d'un élément.
Modifier le contenu // Changer le texte document.getElementById("titre").textContent = "Mes recettes"; // Ajouter du HTML document.getElementById("container").innerHTML = "<p>Nouvelle recette!</p>";
Ajouter des événements
Faire quelque chose quand l'utilisateur agit (clic, saisie, etc.).
Événements let bouton = document.getElementById("valider"); bouton.addEventListener("click", function() { console.log("Le bouton a été cliqué !"); // Faire quelque chose });
Dans Flōra
Quand tu cliques sur une recette, le DOM change : les détails s'affichent, les boutons se mettent à jour. Tout ça sans recharger la page !

💾 localStorage : Sauvegarder les données

Qu'est-ce que c'est vraiment ?

localStorage permet au navigateur de mémoriser des données même après fermeture de la page. C'est comme une petite base de données locale.

⚠️ Important pour les Artifacts Claude
localStorage ne fonctionne PAS dans les artifacts Claude.ai. Mais tu peux l'utiliser dans une vraie app déployée sur GitHub Pages !

Les opérations essentielles

localStorage Syntaxe // Sauvegarder localStorage.setItem("clé", "valeur"); // Récupérer let valeur = localStorage.getItem("clé"); // Supprimer localStorage.removeItem("clé"); // Vider tout localStorage.clear();
Cas d'usage dans Flōra (sur GitHub Pages)
Sauvegarder les recettes favorites, le repas du jour, les préférences de l'utilisateur. Tout reste quand tu reviens demain !

Exemple pratique

localStorage dans Flōra // Sauvegarder une recette favorite function ajouterFavoris(recetteId) { localStorage.setItem("favoris_" + recetteId, "true"); } // Vérifier si une recette est favorite function estFavoris(recetteId) { return localStorage.getItem("favoris_" + recetteId) === "true"; } // Récupérer toutes les favorites let recettes_fav = []; for (let i = 0; i < localStorage.length; i++) { let clé = localStorage.key(i); if (clé.startsWith("favoris_")) { recettes_fav.push(clé); } }

🌐 API : Communiquer avec d'autres services

Qu'est-ce que c'est vraiment ?

Une API (Application Programming Interface) permet à ta page de communiquer avec d'autres serveurs pour récupérer ou envoyer des données.

Exemple simple
Flōra pourrait utiliser une API pour récupérer les infos nutritionnelles depuis une base de données.

Comment faire un appel API avec fetch()

API fetch() basique // Récupérer des données fetch('https://api.exemple.com/recettes') .then(response => response.json()) .then(data => { console.log(data); // Afficher les recettes });

Explication mot par mot

Décortiquer fetch()
fetch() = Envoyer une requête au serveur
.then() = Attendre la réponse, puis faire quelque chose
response.json() = Convertir la réponse en JavaScript
data = Les données reçues (recettes, utilisateurs, etc.)

Exemple : Flōra récupère les recettes

API Flōra (version correcte) function chargerRecettes() { fetch('/data/recettes.json') .then(response => response.json()) .then(recettes => { // Afficher chaque recette recettes.forEach(recette => { afficherRecette(recette); }); }); } function afficherRecette(recette) { let html = "<div class='recette'>" + "<h2>" + recette.nom + "</h2>" + "<p>" + recette.calories + " cal</p>" + "</div>"; document.getElementById("recettes").innerHTML += html; }

🐛 Débogage : Trouver et corriger les erreurs

Qu'est-ce que c'est vraiment ?

Le débogage, c'est l'art de trouver pourquoi ton code ne fonctionne pas. TOUS les programmeurs font des erreurs — c'est normal !

Les types d'erreurs

1. Erreurs de syntaxe
Tu as oublié un point-virgule, une parenthèse, ou écrit un mot clé mal. Le navigateur refuse d'exécuter le code.
Erreur de syntaxe (MAUVAIS) let nom = "Flōra" // Manque le point-virgule let calories = 250; function ajouterRepas() { // Manque une accolade fermante
Correction (BON) let nom = "Flōra"; let calories = 250; function ajouterRepas() { console.log("Recette ajoutée"); }
2. Erreurs logiques
Le code s'exécute, mais ne fait pas ce que tu veux. C'est plus difficile à trouver !
Erreur logique (MAUVAIS) function calculerTotal(calories1, calories2) { return calories1 - calories2; // Oups ! Soustraction au lieu d'addition }
Correction (BON) function calculerTotal(calories1, calories2) { return calories1 + calories2; // Correct : addition }

Comment utiliser la Console du navigateur

Les 3 étapes
1. Ouvre la console : F12 ou Clic droit → Inspecter → Console
2. Ajoute console.log() dans ton code : console.log("Valeur: " + x);
3. Recharge la page et regarde les messages
Utiliser console.log() function ajouterRepas(id) { console.log("ID reçu: " + id); const recette = recettes.find(r => r.id === id); console.log("Recette trouvée: " + recette.nom); monRepas.push(recette); console.log("Total repas: " + monRepas.length); }
Astuce : Les types d'erreurs
console.log() = Information
console.warn() = Attention
console.error() = Erreur grave

✅ Bonnes pratiques : Écrire du code propre

1. Les noms explicites

MAUVAIS let x = 250; function f() { return x * 2; }
BON let caloriesRecette = 250; function doublerCalories() { return caloriesRecette * 2; }

2. Les commentaires

Explique le POURQUOI, pas le QUOI :

Bons commentaires // Filtrer les recettes à moins de 300 cal // pour proposer des options légères let recettesLegeres = recettes.filter(r => r.calories < 300); // Trier par calories croissantes // pour afficher les options les plus légères en premier recettesLegeres.sort((a, b) => a.calories - b.calories);

3. DRY = Don't Repeat Yourself

Si tu écris le même code 2 fois, mets-le dans une fonction !

MAUVAIS (répétition) // Afficher recette 1 let html1 = "<div>" + recettes[0].nom + "</div>"; document.getElementById("r1").innerHTML = html1; // Afficher recette 2 let html2 = "<div>" + recettes[1].nom + "</div>"; document.getElementById("r2").innerHTML = html2; // Afficher recette 3 let html3 = "<div>" + recettes[2].nom + "</div>"; document.getElementById("r3").innerHTML = html3;
BON (utiliser une fonction) function afficherRecette(recette, elementId) { let html = "<div>" + recette.nom + "</div>"; document.getElementById(elementId).innerHTML = html; } // Appeler 1 fois au lieu de 3 recettes.forEach((recette, index) => { afficherRecette(recette, "r" + (index + 1)); });

4. Indentation (aérer le code)

MAUVAIS (illisible) function init(){let container=document.getElementById("recettes");recettes.forEach(recette=>{let div=document.createElement("div");div.className="recette";div.innerHTML="<h3>"+recette.nom+"</h3>";container.appendChild(div);});}
BON (lisible) function init() { let container = document.getElementById("recettes"); recettes.forEach(recette => { let div = document.createElement("div"); div.className = "recette"; div.innerHTML = "<h3>" + recette.nom + "</h3>"; container.appendChild(div); }); }

📖 Lexique complet : Tous les termes

Les termes les plus importants

Array (Tableau)
Une liste d'éléments. Ex: ["Salade", "Soupe", "Gratin"]
Boolean
true (vrai) ou false (faux). Utilisé dans les conditions.
Callback
Une fonction passée à une autre fonction. Ex: forEach(function(item) {...})
Class
Un sélecteur CSS ou une catégorie d'objets en JS
DOM
Document Object Model - la représentation de ta page HTML
Event
Un événement : clic, saisie, survol... Utilisé avec addEventListener()
Function
Un bloc de code réutilisable qui fait une tâche spécifique
ID
Un identifiant unique pour un élément HTML. Ex: id="titre"
Itération
Passer en revue chaque élément d'une liste (avec for ou forEach)
JSON
Format pour écrire des données structurées. Ex: {"nom": "Flōra", "calories": 250}
Method (Méthode)
Une fonction attachée à un objet. Ex: array.forEach(), string.toUpperCase()
Parameter
Une variable passée à une fonction. Ex: function ajout(a, b) {...}
Promise
Une promesse que quelque chose va se passer. Utilisée avec fetch()
Query
Interroger le DOM. Ex: document.querySelector(".recette")
String
Du texte. Ex: "Salade Pois Chiches" ou "Flōra"
Variable
Une boîte qui contient une valeur. Déclarée avec let ou const

💪 Exercices progressifs

Niveau 1 : Variables et fonctions

Exercice 1.1 : Calculer les calories

Crée une fonction qui multiplie les calories par 1.5 (si tu veux faire une double portion)

À compléter function doubleCalories(calories) { // À toi : retourner calories * 1.5 } console.log(doubleCalories(250)); // Doit afficher 375
Solution function doubleCalories(calories) { return calories * 1.5; }

Niveau 2 : DOM et événements

Exercice 2.1 : Afficher/Cacher des détails

Crée un bouton qui affiche/cache les détails d'une recette

À compléter function toggle() { let details = document.getElementById("details"); // À toi : vérifier si details.style.display === "none" // Si oui, mettre à "block" // Si non, mettre à "none" }
Solution function toggle() { let details = document.getElementById("details"); if (details.style.display === "none") { details.style.display = "block"; } else { details.style.display = "none"; } }

Niveau 3 : Boucles et filtrage

Exercice 3.1 : Filtrer les recettes légères

Crée une fonction qui retourne seulement les recettes à moins de 300 cal

À compléter const recettes = [ { nom: "Salade", calories: 200 }, { nom: "Pizza", calories: 400 }, { nom: "Soupe", calories: 150 } ]; function recettesLegeres() { // À toi : utiliser .filter() pour retourner calories < 300 } console.log(recettesLegeres()); // Doit retourner Salade et Soupe
Solution function recettesLegeres() { return recettes.filter(r => r.calories < 300); }
